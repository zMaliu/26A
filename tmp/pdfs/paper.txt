        本文将圆柱形药材视为轴对称连续介质，建立径向热传导–水分扩散耦合模型。
      问题一采用常物性有限体积/有限差分格式，问题二、三采用附录 3 变物性半隐式格

      便于复核和复现实验。



                       1   问题重述

1.1   问题背景
  中药材干燥是影响成品品质的重要工序，热风烘干是常用方式之一。该过程通常分
为预热平衡与恒温干燥两个阶段，通过调节烘房温湿环境实现药材脱水。烘干时，工艺
参数若选择不合理，会造成干燥效率低、能耗高、品质波动等问题；传统试验优化又存
在成本高、周期长等局限。为了解决这些问题，本文将采用数理分析与数值仿真方法，
研究中药材烘干过程中的变化规律。

                 2   问题分析

2.1 问题一分析
  对于问题一，问题一要求在预热平衡阶段，建立圆柱形中药材内部温度与水分浓度
时空演化的数学模型，并计算特定时刻与径向位置的数据。这本质上是一个“给定外部
热湿环境边界后，求解药材内部非稳态传热传质耦合偏微分方程的初边值问题”。
  首先，从物理机理层面分析。中药材内部存在细胞、孔隙、毛细通道与固体骨架，结
构极其复杂。由于题目提供的密度、比热容、导热系数与有效扩散系数均为宏观等效系
数，且考虑到孔隙尺度 CFD 模型所需条件尚不充分，本文采取宏观连续介质假设，将
药材划分为许多微小控制体，每个控制体用平均温度与平均水分浓度来描述，从而建立
宏观连续介质模型。
    其次，针对几何与传热传质特征进行合理简化。考虑到药材为圆柱形，且初始温度
与水分浓度分布均匀，忽略轴向与圆周方向的变化，可将三维问题退化为沿半径方向的
** 一维径向模型 **。在控制方程建立上，热量传递以导热为主，遵循傅里叶定律与能
量守恒；水分迁移以扩散为主，遵循有效 Fick 定律与质量守恒。需要注意的是，水分扩
散系数 D 并非常数，而是水分浓度 C 与温度 T 的非线性函数，这使得模型呈现强非线
性特征。在边界条件方面，药材中心满足对称条件（绝热绝质），表面则与烘房环境发
生对流换热与对流传质，属于第三类边界条件。
  在模型求解层面，由于该非线性偏微分方程组难以获得解析解，本文按问题分别采
用显式和半隐式有限体积/有限差分格式：问题一采用显式格式，问题二、三采用系数
滞后的半隐式格式，问题四在材料坐标上采用后向 Euler、系数滞后的线性化隐式控制
体格式。求解过程中面临两个核心难点：一是附件 1 提供的烘房环境数据是离散的，且
边界值在时间推进中需要连续查询，因此本文引入 **PCHIP 插值 **，避免非物理过冲；
二是空间离散时需妥善处理圆柱中心的坐标奇点以及表面的通量平衡。为此，本文利用
中心控制体处理奇点，并基于有限体积法思想，引入界面扩散系数的算术平均，从而保
障数值计算的稳定性与离散守恒性。
  最后，为保证计算结果的可靠性，本文在数值求解后，分别从全局能量守恒与水分
质量守恒两个维度对算法进行守恒性验证，确保相对误差远小于工程容许阈值，最终输
出满足精度要求的温度场与水分场分布结果。

                  4   问题一的模型的建立和求解

4.1   模型选取
  在建立中药材热风干燥数学模型前，需明确描述传热传质过程的数值模拟方法。根
据现有研究，农产品热风干燥的数值模拟方法主要可分为三类：干燥动力学模型、连续
介质假设模型和孔道网络模型。
  干燥动力学模型以薄层干燥为对象，通过水分比等指标描述平均水分浓度变化。其
优点是形式简单、计算量小，能快速预测干燥特性；但多依赖经验参数，物理机理不明
确，难以刻画内部温度与水分浓度的空间分布。
  连续介质假设模型将中药材视为等效多孔介质，基于质量、能量和动量守恒建立偏
微分控制方程。其优点是能从宏观尺度描述温度场与水分浓度场的时空演化，物理意义
清晰，计算效率较高，是农产品干燥研究中最常用的方法。但该方法基于连续性假设，
对具有各向异性或复杂孔隙结构的物料描述不够精细。
  孔道网络模型从物料内部孔隙结构出发，将多孔介质离散为节点与孔道网络，通过
毛细压力、蒸发冷凝等机制模拟水分迁移。其优点是能反映真实孔隙结构的影响，可解

释“湿斑”和“不规则前沿”等现象；但建模复杂、计算量大，三维模拟尚不成熟，难
以直接应用于工程尺度预测。
  综上，三类方法各有侧重。考虑到题目给出的密度、比热容、导热系数与有效扩散
系数均为宏观等效系数，且问题需要获取药材内部温度与水分浓度的时空变化规律及烘

4.2     模型建立：热质传递控制方程的建立
4.2.1   热量守恒方程

  取药材内部一微元控制体，由能量守恒定律可知：单位时间内控制体内热量的累积
等于净流入控制体的热量与内热源生成热量之和。本文忽略内热源，则单位体积内热量
的累积率可表示为
                           ∂T
                  Qv = ρcp                (1)
                           ∂t
式中，Qv 为单位体积热量累积率，ρ 为药材密度，cp 为药材比热容，T 为药材内部温
度，t 为时间。
  药材内部热量主要以导热方式传递。根据傅里叶定律，热流密度与温度梯度成正比、
方向相反，即
                 q = −k∇T            (2)
式中，q 为热流密度矢量，k 为药材热传导系数，∇ 表示梯度算子，∇· 表示散度算子。

                              ∂t
将式 (2) 代入式 (3)，得到药材内部温度场的控制方程

                Jc = −D∇C               (5)

4.3     初始条件与边界条件
4.3.1   初始条件

      烘干开始时，药材内部温度和水分浓度分布均匀，由题意可得

           T (r, 0) = 28◦ C,    C(r, 0) = 2.55 kg/kg,     0≤r≤R   (12)

式中，R 为药材半径。根据题目给定尺寸，半径 R = 0.02 m。


4.3.2   中心对称条件

      在圆柱中心 r = 0 处，由对称性可知热流密度与水分通量均为零，即
                           ∂T                ∂C
                                  = 0,              =0            (13)
                           ∂r r=0            ∂r r=0

4.3.3   表面对流换热条件

   烘房空气通过对流将热量传递给药材，药材表面温度不一定等于空气温度，药材
内部导热与外部对流共同决定其升温过程。由于题目未直接指定药材表面温度，采用
Newton 对流边界条件：
                  ∂T
               −k        = h [T (R, t) − Tf (t)] (14)
                  ∂r r=R
式中，h 为对流换热系数，Tf (t) 为烘房温度，其随时间的变化由附件 1 给出。


4.3.4 表面对流传质条件

  药材表面水分浓度与空气水分浓度之间存在差异，水分先从药材内部扩散至表面，
再通过气膜传递至空气中。因此，药材表面满足对流传质边界条件
                           ∂C
                      −D          = hm [C(R, t) − Cair (t)]       (15)
                           ∂r r=R

式中，hm 为对流传质系数，Cair (t) 为烘房空气水分浓度，其随时间的变化由附件 1 给
出。


4.4     模型求解
  本文建立的一维径向传热传质控制方程属于非线性偏微分方程组，难以获得解析
解。为此，本文采用显式有限差分法（FDM）对空间域和时间域进行离散，通过时间推
进循环求解药材内部温度和水分浓度的时空分布。

4.4.1   时空离散与网格划分

位置为 ri = i∆r（i = 0, 1, . . . , Nr − 1）

8.2   误差分析
     数值误差与模型误差分别讨论。由表 2 可知，时间步减半后误差约减半，空间步
减半后误差约变为四分之一，故在当前网格下时间离散误差和空间离散误差均已进入稳

5 × 10−5 ；5500 s 断点比较的最大误差也小于 10−4 。
  模型误差主要来自连续介质假设、圆柱一维径向化、Robin 边界系数和经验物性公
式的适用范围，以及环境数据插值。由于题目未提供完整实验时空场，本文不能用实验
真值给出统计置信区间，因此采用独立重算、收敛性、守恒性和物理约束四类互相独立
的证据评价结果可靠性。这些检验分别对应“文件是否写对”“离散是否收敛”  “方程是
否守恒”和“结果是否符合物理”，共同构成对三问数值答案的交叉证明。

157 def solve_tridiag (a, b, c, d):
158     # 追赶法
159     n = len (b)
160     cp = np. zeros (n)
161     dp = np. zeros (n)
162     if abs (b [0]) < 1e -14:
163          raise ZeroDivisionError (" Singular tridiagonal system at
                  first row ")
164     cp [0] = c [0] / b [0]
165     dp [0] = d [0] / b [0]
166     for i in range (1 , n):
167          m = b[i] - a[i] * cp[i - 1]
168          if abs (m) < 1e -14:
169               raise ZeroDivisionError (f" Singular tridiagonal
                      system at row {i}")
170          if i < n - 1:
171               cp[i] = c[i] / m
172          dp[i] = (d[i] - a[i] * dp[i - 1]) / m
173     x = np . zeros (n)
174     x[ -1] = dp [ -1]
175     for i in range (n - 2, -1, -1):
176          x[i] = dp [i] - cp[i] * x[i + 1]
177     return x

            = float )

              dt)])

438           rho_of_C (C [: -1]) * cp_of_C (C [: -1]) * (T [1:] - T [: -1]) *
                    V,

            = float )

443     energy_residual = abs (np. sum ( thermal_storage ) - np. sum (
            q_flux_step * dt))
444     energy_scale = max ( abs (np. sum ( thermal_storage )), 1e -12)
445     energy_rel_err = energy_residual / energy_scale

101   def solve_tridiag (a, b, c, d):
102       # 追赶法
103       n = len (b)
104       if n == 0:
105            return np. empty (0)
106       cp = np. zeros (n)
107       dp = np. zeros (n)
108       if abs (b [0]) < 1e -14:
109            raise ZeroDivisionError (" 三 对 角 矩 阵 首 行 奇 异 ")
110       cp [0] = c [0] / b [0]
111       dp [0] = d [0] / b [0]
112       for i in range (1 , n):
113            den = b[i] - a[i] * cp[i - 1]
114            if abs ( den ) < 1e -14:
115                 raise ZeroDivisionError (f" 三 对 角 矩 阵 第 {i} 行 奇 异 ")
116            if i < n - 1:
117                 cp[i] = c[i] / den
118            dp[i] = (d[i] - a[i] * dp[i - 1]) / den
119       x = np . zeros (n)
120       x[ -1] = dp [ -1]
121       for i in range (n - 2, -1, -1):
122            x[i] = dp [i] - cp[i] * x[i + 1]
123       return x

126 def _assemble_scalar (old , coeff , storage , radius , dt , dx ,
127                           boundary_value , boundary_coeff ):
128     # 组装隐式方程
129     nr = len ( old )
130     x = np . linspace (0.0 , 1.0 , nr)
131     w = np . zeros (nr)
132     w [0] = (dx / 2.0) ** 2
133     w [1: -1] = 2.0 * x [1: -1] * dx
134     w[ -1] = 1.0 - (1.0 - dx / 2.0) ** 2
135     a = np . zeros (nr)
136     b = np . ones (nr )
137     c = np . zeros (nr)
138     d = old . copy ()
139     # 内部扩散通量
140     face_x = (np. arange (nr - 1) + 0.5) * dx
141     for f in range (nr - 1):
142           xi_face = face_x [f]
143           left , right = f, f + 1
144           # 相邻控制体共用通量
145           g_left = 2.0 * dt * xi_face * coeff [f] / ( radius **2 *
                  storage [ left ] * w[ left ] * dx)
146           g_right = 2.0 * dt * xi_face * coeff [f] / ( radius **2 *
                  storage [ right ] * w[ right ] * dx)
147           c[ left ] -= g_left
148           b[ left ] += g_left
149           a[ right ] -= g_right
150           b[ right ] += g_right
151     # 表面对流项
152     g_conv = 2.0 * dt * boundary_coeff / ( radius * storage [ -1]
            * w [ -1])
153     b[ -1] += g_conv
154     d[ -1] += g_conv * boundary_value
155     return a, b, c, d
